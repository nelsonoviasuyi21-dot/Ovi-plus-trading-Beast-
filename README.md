# Ovi Plus Trading Beast

Advanced Android dashboard for the Ovi Plus Trading Beast cloud paper-trading engine.

## Features

- Premium dark trading dashboard
- Live cloud connection
- Live activity event stream
- Scanner intelligence
- Candidate score
- Buyer strength
- Active position monitoring
- Portfolio statistics
- Start
- Stop
- Resume
- Emergency stop
- Scan now
- Automatic cloud polling
- One-entry/no-reentry display
- 55/100 minimum score
- 70% minimum buyer strength

## Backend

https://ovi-plus-trading-beast.onrender.com

## Trading mode

Paper trading only.

The APK does not contain wallet private keys, transaction signing,
or blockchain broadcast functionality.
